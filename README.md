# Alexis Larin portfolio

Static portfolio based on the selected A4 design direction.

## Local development

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://127.0.0.1:5173`).

## Checks

```sh
npm run build
```

The page is deliberately build-light: `index.html` contains the semantic
content and `styles.css` contains the responsive visual system.
